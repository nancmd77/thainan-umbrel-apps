# Thainan Umbrel Community App Store

Community App Store for [umbrelOS](https://umbrel.com), curated for Thainan Caldeira.

**Store ID:** `thainan`  
**Clone URL:** `https://github.com/nancmd77/thainan-umbrel-apps.git`

## Add on Umbrel

1. Umbrel → App Store → three-dot menu → **Community App Stores**
2. Paste: `https://github.com/nancmd77/thainan-umbrel-apps`
3. Or CLI: `sudo ~/umbrel/scripts/repo add https://github.com/nancmd77/thainan-umbrel-apps && sudo ~/umbrel/scripts/repo update`

See [TRIAGE.md](./TRIAGE.md) for INCLUDE/SKIP decisions and required secrets.

Based on the [Umbrel Community App Store template](https://github.com/getumbrel/umbrel-community-app-store).
